Send automated Meta WhatsApp appointment confirmations, reminders, and cancellations for Amelia Bookings. Zero Markup WhatsApp API alternative to Twilio.

== Description ==

Stop losing revenue to missed appointments. The **WhatsApp Notifications for Amelia Booking** plugin connects your Amelia scheduling system directly to the Official Meta WhatsApp Cloud API via 5MinutesAPI.

When a client books an appointment, clinic visit, or salon service on your WordPress site, this plugin automatically sends a verified WhatsApp Template message to their phone. WhatsApp has a 98% open rate compared to standard emails or expensive SMS.

**Why 5MinutesAPI? (The Smart Twilio Alternative)**
Unlike Wati, Twilio, or MessageBird, 5MinutesAPI charges **Zero Markup** on your WhatsApp messages. You only pay for what Meta charges, with no hidden per-message fees. 

**Core Features for Clinics, Salons & Agencies:**
* **Instant Confirmations:** Send WhatsApp alerts the second an Amelia booking is created.
* **Meta Approved Templates:** Uses official Meta API to prevent number banning.
* **Zero Code Setup:** Just paste your 5MinutesAPI Master Key and go live.
* **Global Delivery:** 100% reliable WhatsApp delivery across 180+ countries.
* **Bypass Business Verification:** Use our Instant OTP & Alert gateway without waiting weeks for Meta business verification.

**How to get started in 2 minutes:**
1. Create a free account at [5MinutesAPI.com](https://5minutesapi.com).
2. Generate your Master API Key from the dashboard (Zero Markup API).
3. Paste the key into this plugin's settings.

== Installation ==

1. Upload the plugin folder to the `/wp-content/plugins/` directory, or install directly through the WordPress plugins screen.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Go to **Settings -> Amelia WhatsApp** and enter your Master API Key.
