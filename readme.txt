Send automated appointment confirmations, reminders, and cancellations for Amelia Bookings using the 5MinutesAPI platform. The smarter Twilio alternative.

== Description ==

Stop losing revenue to missed appointments. The **5MinutesAPI Notifications for Amelia Booking** plugin connects your Amelia scheduling system directly to our high-speed global messaging API.

When a client books an appointment, clinic visit, or salon service on your WordPress site, this plugin automatically sends an instant alert to their phone. (Powered by the Official Meta WhatsApp Cloud API via 5MinutesAPI).

**Why 5MinutesAPI? (The Smart Twilio Alternative)**
Unlike Wati, Twilio, or MessageBird, 5MinutesAPI charges **Zero Markup** on your messages. You only pay for what Meta charges, with no hidden per-message fees. 

**Core Features for Clinics, Salons & Agencies:**
* **Instant Confirmations:** Send alerts the second an Amelia booking is created.
* **Official Gateway:** Uses official Meta API to prevent number banning.
* **Zero Code Setup:** Just paste your 5MinutesAPI Master Key and go live.
* **Global Delivery:** 100% reliable delivery across 180+ countries.

**How to get started in 2 minutes:**
1. Create a free account at [5MinutesAPI.com](https://5minutesapi.com).
2. Generate your Master API Key from the dashboard (Zero Markup API).
3. Paste the key into this plugin's settings.

== Installation ==

1. Upload the plugin folder to the `/wp-content/plugins/` directory, or install directly through the WordPress plugins screen.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Go to **Settings -> 5MinutesAPI Amelia** and enter your Master API Key.
